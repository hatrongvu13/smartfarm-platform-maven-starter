# V0.1-001 — Fix `test`-profile security config (flat → nested `jwt.*`)

```
ID:            V0.1-001
Title:         application-test.yml dùng flat security key → service không boot ở profile `test`
Status:        TODO
Priority:      P0 (blocker cho CI / profile `test`; KHÔNG chặn prod)
Type:          CONFIGURATION / BUG
```

## Scope
Sửa 6 file `application-test.yml` sang dạng lồng `smartfarm.security.jwt.{issuer,jwk-set-uri,audiences}` (plural).

## Out of Scope
Không chạm `src/main` Java, Flyway, proto, hay prod/dev YAML (prod/dev đã đúng; ISSUE-01 đã vá).

## Related Components
`libs/smartfarm-security` record `SmartFarmSecurityProperties` (compact constructor + `Jwt` record).

## Current State (FACT — verified 2026-10-03)
`SmartFarmSecurityProperties` là `@ConfigurationProperties(prefix="smartfarm.security")` với `@NotNull Jwt jwt`;
compact constructor ném `IllegalArgumentException("smartfarm.security.jwt is required")` nếu `jwt == null`.
`Jwt` dùng `audiences` (Set, plural). 6/7 `application-test.yml` lại viết **flat/singular**:
```yaml
smartfarm:
  security:
    issuer: http://localhost:8092
    jwk-set-uri: http://localhost:8092/.well-known/jwks.json
    audience: smartfarm-<svc>
    allow-local-http: true
```

## Problem
Chạy với `SPRING_PROFILES_ACTIVE=test` (hoặc `@ActiveProfiles("test")`) → `jwt` bind null → compact
constructor ném exception → context fail → **service không boot**. Đây là **lặp lại pattern ISSUE-01** vào
profile `test`. (Các IT hiện tại KHÔNG dính vì chúng ghi đè nested `jwt.*` INLINE qua `@SpringBootTest(properties=...)`
và không bật profile `test`.)

## Evidence
- Affected: `services/{finance,health,inventory,livestock,order,reporting}-service/src/main/resources/application-test.yml`
- Correct reference: `services/smartfarm-identity-service/src/main/resources/application-test.yml` (đã dùng nested `jwt.*`).
- Record: `libs/smartfarm-security/src/main/java/com/htv/smartfarm/security/config/SmartFarmSecurityProperties.java`.

## Expected State
Cả 6 file dùng nested form; service boot ở profile `test`.
